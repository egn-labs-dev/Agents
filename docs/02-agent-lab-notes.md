# Нотатки: Vertex AI Agent Builder Lab (Тиждень 2)

## 🎯 Огляд архітектури Agent Builder (2026)
Vertex AI Agent Builder об'єднує можливості пошукових систем (Discovery Engine) та розмовного ШІ (за базі Playbooks / Dialogflow CX). Він дозволяє декларативно описувати поведінку агента, підключати корпоративні знання (Data Stores) та розширювати логіку через інструменти (Tools).

---

## 🛠️ Покроковий гайд для створення DevOps Assistant

### 1. Створення Data Store (Бази знань)
1. Перейдіть у **Vertex AI Agent Builder** -> **Data Stores**.
2. Натисніть **Create Data Store** та оберіть **Cloud Storage**.
3. Вкажіть шлях до бакету з файлом `k8s_runbook.txt` (створеним на попередньому кроці). Оберіть тип **Unstructured documents**.
4. Назвіть дата-стор: `k8s-runbook-store`.

### 2. Створення Агента (App)
1. Перейдіть у **Apps** -> **Create New App**.
2. Оберіть тип **Agent** (або *Chat*, залежно від поточного UI розкладки).
3. Назва застосунку: `devops-assistant`.
4. Регіон (Location): `global` або `europe-west3` (рекомендовано для мінімізації затримок).

### 3. Конфігурація Playbook / Системних інструкцій
У полі **Goal** або **System Instructions** вставте наступний текст:
```text
Ти — висококваліфікований DevOps-інженер та SRE-асистент. Твоя мета — допомагати команді розробників діагностувати проблеми з інфраструктурою, аналізувати деплої та надавати точні інструкції на основі підключених інструментів та бази знань.

ОБМЕЖЕННЯ:
- На запитання про падіння подів (Pod CrashLoopBackOff, OOMKilled тощо) ЗАВЖДИ використовуй підключену базу знань `k8s-runbook-store`.
- Якщо інформації немає в базі знань, чітко скажи про це і запропонуй базові команди діагностики (kubectl).
- Відповідай чітко, структуровано, мовою запиту користувача.
```
